# wardrobe

Игра «Гардероб»: движок и звуки. Блок для Тильды — в репо `code`, папка `wardrobe/`; он подключает `wardrobe.js` отсюда по хэшу коммита.

| Файл | Что это |
|---|---|
| `wardrobe.js` | движок игры: сцены, одежда, сортировка, звёзды, интерфейс |
| `clean`, `dirty`, `smell-good`, `smell-bad`, `dry`, `wet`, `smooth`, `wrinkled`, `wardrobe` `.m4a` | озвучка знакомства (голос Софьи) |
| `task-dirty`, `task-wet`, `task-wrinkled` `.m4a` | инструкции звёзд 2–4 (голос Софьи) |
| `wash.m4a` | стирка в машинке |
| `place.m4a` | вещь в шкаф (аккорд маримбы до–ми–соль–до) |
| `rack.m4a` | мокрая вещь на сушилку (ми–соль–ля, до) |
| `iron.m4a` | глажка: три прохода утюга |
| `steps`, `grab`, `dress`, `tug`, `thumb` `.m4a` | сценка с девочкой: шаги (одна дорожка на всю ходьбу), вешалка, надевание, одёргивание, «класс» |

Общие звуки берутся из других репо: звезда и фанфары — `Otvlekashki`, похвала `Rock3`–`Rock9` — `sofia-game-image`, фоновая музыка и картинка звезды — `sofia-game2`.

Для проверки в консоли: `__sg.go(k)` — сразу к звезде k (0 — знакомство, 1 — грязное, 2 — мокрое, 3 — мятое).

## «Гардероб 2»: по погоде и по случаю — папка `w2/`

Блок для Тильды — в репо `code`, папка `wardrobe2/`; он подключает `w2/wardrobe2.js` отсюда по хэшу коммита.

| Файл | Что это |
|---|---|
| `w2/wardrobe2.js` | движок: вступление (звезда 1), одевание по погоде, по случаю и для занятий (звёзды 2–4), мультики, звёзды, финал |
| `i1`–`i4`, `zhar`, `dozhd`, `sneg`, `osen`, `sport`, `prazd`, `bass`, `son`, `kuh`, `vel`, `og`, `fut`, `d`, `m` `.m4a` | озвучка (голос Софьи). Движок ищет файл сначала в `w2/`, потом в корне репо; если файла нет — держит паузу по длине фразы |
| `w2/kalimba.m4a` | надевание вещи |
| `w2/amb-*.m4a` | звук места: лето, дождь, осень, зима, спортзал, праздник, бассейн, ночь, стадион, кухня |
| остальные `w2/*.m4a` | звуки мультиков: дождь, зонт, шаги, всплески, звонок, мяч и т. п. |
| `w2/src/` | исходник превью `src2.html` и сборка `build_prod.py` + `shell.js` (`python3 build_prod.py` → `wardrobe2.js`) |

Общие звуки: звезда, фанфары и «верно» — `Otvlekashki`, похвала `Rock3`–`Rock9` — `sofia-game-image`, фоновая музыка и картинка звезды — `sofia-game2`. Фоновая музыка по умолчанию выключена.

Для проверки в консоли: `__sg.star(n)` — сразу к звезде n (2–4).
